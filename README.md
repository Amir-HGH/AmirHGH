## 🚀 Featured Project

### AFilm Bot — AI-Powered Movie & TV Series Recommendation Agent

AFilm Bot is a Telegram-based AI agent designed to provide personalized movie and TV series recommendations.

The project combines multiple recommendation techniques with an LLM-powered agent to deliver intelligent and context-aware suggestions.

**Key Features:**
- AI Agent architecture built with LangGraph.
- LLM integration with custom tools through Tool Calling.
- Hybrid recommendation pipeline combining Semantic Search, Collaborative Filtering, and business rules.
- Personalized recommendations based on user interactions.
- Conversation and user interaction management.
- MySQL integration for data storage and retrieval.

**Technologies:** Python, LangGraph, LangChain, FAISS, Sentence Transformers, LightFM, MySQL, PyMySQL, Telegram Bot API.
